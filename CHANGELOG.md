# Changelog

All notable changes to localShare are documented here.

## [1.0.0] - 2026-11-03

### Added
- Cross-platform desktop file sharing over the local network.
- Two-way transfers (download and upload) via any browser.
- Optional password protection and upload size limits.
- QR code access, dark/light themes, list/grid view.
- Automatic updates on Windows.
- Hardened path handling and upload validation.

### Notes
- First stable release.
